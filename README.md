# 🚀 Dropshipping AI Builder

Site de dropshipping dynamique avec **Mistral AI** et déployé sur **Vercel**.

## ⚡ Démarrer en 2 minutes

**Cliquez ici pour déployer:**
https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fbraouyka-ai%2Fmon-site-jade&env=MISTRAL_API_KEY

Entrez votre clé API Mistral et c'est fait!

Lire le [Guide de démarrage](GETTING_STARTED.md) pour les détails.

## 🛠️ Configuration locale (optionnel)

```bash
git clone https://github.com/braouyka-ai/mon-site-jade.git
cd mon-site-jade
npm install
echo "MISTRAL_API_KEY=votre_cle_ici" > .env.local
npm run dev
```

Accédez à http://localhost:3000

---

## 📝 Variable d'environnement

- `MISTRAL_API_KEY` - Votre clé API Mistral (https://console.mistral.ai/)
